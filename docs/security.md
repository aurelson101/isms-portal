# Sécurité

Secrets par Docker secrets ou gestionnaire externe, jamais dans Git. TLS,
validation stricte, en-têtes de sécurité, limites de débit/taille, contrôle MIME,
ClamAV, identifiants objets non prédictibles et autorisation backend sont
obligatoires. Renouveler les secrets et auditer dépendances/images régulièrement.
