# Active Directory

Créer un compte de service en lecture seule, sans ouverture de session
interactive. Autoriser uniquement la lecture des utilisateurs, groupes et
appartenances nécessaires. Utiliser LDAPS 636, deux contrôleurs, un Base DN
minimal et des filtres LDAP échappés. Groupes par défaut : `Domain Users`,
`ITAD`, `HRAD`, `FINANCEAD`, `MANAGEMENTAD`, `ISMS-ADMINS` et
`ISMS-SUPER-ADMINS`.
