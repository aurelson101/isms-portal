# Guide utilisateur

Le portail reconnaît automatiquement votre identité professionnelle. Utilisez la
recherche ou les catégories Politiques, Procédures et Guides. Seuls les espaces
et documents autorisés sont visibles. Le sélecteur FR/EN mémorise votre choix.

Les PDF s’ouvrent dans le lecteur intégré. Les fichiers Word DOCX et Excel XLSX
s’affichent dans une vue locale en lecture seule. Le téléchargement peut être
désactivé par l’administrateur indépendamment du droit de consultation.
